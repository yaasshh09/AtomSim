Privacy

Last updated 24 October 2026

AtomSim has no accounts, no sign-up and no cookies. You can use all of it without telling it who you are. Here is everything that does get recorded when you visit.

Visit counting

Each time the page opens, it sends one request to GoatCounter so I can see roughly how many people use the site. That request contains:

  • the page path (always /)
  • the page title
  • the site that linked you here, if your browser shares it
  • your screen width, to tell phones from desktops
  • whether the browser looks automated, so test scripts are not counted as people

It does not include which atom, orbital or view you were looking at. GoatCounter sets no cookie and does not store your IP address. It turns your address and browser into a hash that changes every day, which is how it can count unique visitors without being able to follow you around. Their own policy is at goatcounter.com/help/privacy.

Server logs

The site runs on Fly.io. Like most web servers, it writes a line for each request: the time, the address it came from, the path and the response code. These logs exist to keep the site running and to debug problems. I don't use them to identify anyone, and they are not shared or sold. Fly.io keeps them for a limited time under its own privacy policy.

Error reports

If the page crashes in your browser, it sends the error message, the technical stack trace, the page path (without the part after the "?") and the app version to the server, which writes them to the same logs as above. Nothing else goes with them: no identifier, no cookie, and none of what you were looking at. It sends each distinct error once, and at most five per visit. These reports exist only so that bugs get fixed.

Rate limiting

Running a simulation takes real CPU time, so the server limits how many simulations one address can start in a short window. It does this with a small table kept in memory, keyed by IP address. The table is never written to disk, and it is cleared whenever the server restarts.

What stays in your browser

The state you are viewing (the atom, the quantum numbers, the view) is kept in the page address so you can bookmark or share it. That address goes wherever you choose to paste it, and nowhere else.

Questions
